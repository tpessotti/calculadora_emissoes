# Logo da CMP

Para exibir o logo na landing page, coloque o arquivo de imagem do logo da CMP na raiz do projeto com o nome:

```
logo_cmp.png
```

## Especificações Recomendadas:

- **Formato:** PNG com fundo transparente
- **Dimensões:** Largura recomendada 200-400px
- **Localização:** Pasta raiz do projeto (`calculadora_emissoes/`)

## Identidade Visual CMP:

### Cores:
- **Verde Principal:** `#4c8061` 
- **Fundo Claro:** `#EDF0E7`
- **Destaque Laranja:** `#f4b266`

### Fontes:
- **Títulos e Corpo:** Poppins (300, 400, 600, 700)
- **Código/Monospace:** Space Mono (400, 700)

---

Se o arquivo `logo_cmp.png` não for encontrado, a aplicação continuará funcionando normalmente, apenas sem exibir o logo na landing page.
